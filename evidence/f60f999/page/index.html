Disclosed adaptations

  • Venue: the owner's own Intents account holds the assets; the owner registers the guard's derived Ed25519 key there with add_public_key (Claw Guard: owner approves the derived address as a Hyperliquid API wallet). Unlike an API wallet, an Intents key is not trade-only; only the guard's payload construction restricts it.
  • Payload: NEP-413 token_diff over exactly USDC and wNEAR, signer = owner, built by the guard; Ed25519 domain 1 instead of secp256k1 domain 0.
  • Deadline: finite order TTL of 60 s, the mandate's value (Claw Guard's Hyperliquid orders carry no expiry).
  • Nonce: 32-byte legacy (non-versioned) nonce derived from the receipt id, accepted by verifier v0.4.5.
  • Caps in USDC units: per-order token and notional caps, daily notional cap, daily order count, permission expiry; notional of a wNEAR sell is the agent's minimum USDC (Claw Guard Q-42 analog).
  • Omitted as irrelevant to these cases: guardian role, set_rules loosening delay, receipt ring buffer, storage reserve rule, mainnet refusal, Hyperliquid/EVM encoders.

Not guaranteed

  • No guarantee of principal, profit or execution availability.
  • No maximum total loss: market moves, stale references, fees and orders still executable when the breaker trips can lose more than the stated concession.
  • The loss breaker stops new authorizations only; it is not a total-loss cap.
  • The owner stays trusted and keeps deployment/upgrade authority.
  • An adversarial agent can still make economically poor permitted trades.
  • NEAR, the Intents verifier and the token contracts must keep functioning; recovery also needs owner gas.
  • While revoking (before confirmed removal), already-signed orders may still execute.

Unknowns and open risks

  • Sandbox execution only: MPC signer, oracle and tokens are labelled test doubles; the verifier is the pinned mainnet WASM.
  • No mainnet execution in this run; network latency on mainnet is not represented by sandbox timing.
  • The model step replays a recorded interaction; the claude-cli harness may add context that the recording cannot show.
  • Concession bounds, randomized interleavings and breaker behaviour are covered by the Rust gate tests, not by this story.
  • No mainnet receipts: encoding, key registration, the real MPC signer, settlement and recovery on mainnet are not evidenced here.
