Bounded Mandate · revocable trading on NEAR Intents

Give an AI agent trading authority without unrestricted control of your treasury.

Pausing a trading agent doesn't void orders it already signed. Here the agent trades within your limits: the contract builds and checks each order before requesting its MPC signature. Revoke removes the signing key, so signed orders not yet executed fail once removal is confirmed, and you recover the assets without the agent.

Mainnet, 14 Nov 2026: 1 USDC trade filled → key revoked → the same held signed order rejected 67.25 s before expiry → assets recovered · Verify ↓

How it works

The agent can only propose. The contract prices the order, checks it against the owner's limits, and only then asks the MPC network to sign it.

  • Every signed intent is checked against the key registered for the mandate at intents.near. Revoke removes that key, so every outstanding signed order fails once the removal is confirmed.
  • Recover returns the assets to the owner's Intents account. It needs no agent, oracle or MPC.

Limitations

  • Revocation takes effect after the key removal is confirmed. Orders executed before that stay executed.
  • The sandbox uses labelled test doubles for the MPC signer, the oracle and the tokens, with the real pinned Intents verifier.
  • "Certified" means the project's own acceptance gate, not an external audit.
  • No guarantee of principal or profit. Limits bound what the agent can sign, not market outcomes.
  • The owner and the NEAR and NEAR Intents infrastructure are trusted.
  • Revocation's advantage over waiting for expiry is bounded by the order's remaining lifetime (120 s maximum in this run).
  • Mainnet evidence is one small run with fixed proposals, not a live model.
  • The mainnet trade was filled by our own account, not third-party liquidity or the solver network.

Glossary
Function-call key
A NEAR access key limited to one contract and named methods. The agent's key can only call propose_order.
Chain Signatures (MPC)
NEAR's multi-party signing service at v1.signer. The mandate asks it to sign with a key derived for the grant; the agent never holds that key.
NEAR Intents verifier
The intents.near contract. It executes a signed intent only if the signing key is registered for the account.
Withheld order
An order that was signed but not relayed yet. Whoever holds it can relay it until its deadline.
Revoke vs recover
Revoke removes the grant's key, so outstanding signed orders fail. Recover moves the assets back to the owner's Intents account.
